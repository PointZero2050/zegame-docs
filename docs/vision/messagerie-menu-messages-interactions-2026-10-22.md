# Menus des messages : conserver les trois interactions

> Note Codex — précision directe de Boris pendant la recette navigateur du
> 22 octobre 2026. Boris indique avoir également prévenu Claude.
> Cette précision remplace l’interprétation « les … servent exclusivement à la
> gestion » dans les notes précédentes de Codex.

## Fonctionnement à conserver

Les trois interactions **Smiley**, **Réagir** et **Répondre** restent également
accessibles dans le menu « … » de chaque message et de chaque réponse, en
complément des accès compacts dans le pied.

Le menu conserve les opérations de gestion déjà prévues selon l’auteur, les
droits et le contexte : **Modifier**, **Mémoire** (conserver ou demander à
conserver, retrait selon l’état) et **Supprimer**. Ne pas retirer les gardes
existantes pour obtenir artificiellement le même menu sur tous les messages.

Les trois entrées utilisent les mêmes icônes et ouvrent les mêmes interfaces
que les accès du pied :

- Smiley : choix et détail des smileys.
- Réagir : fenêtre **Tes résonances**, avec Ombre, Lumière et Point Zéro.
- Répondre : réponse ciblée sur le message ou la réponse considérée, dans la
  même discussion racine lorsque celle-ci existe.

Ne pas doubler une réaction, un compteur ou une réponse parce que deux entrées
ouvrent la même action. Les conditions de lecture seule, espace clos, type de
contribution et consentement restent celles de l’application.

La réduction du pied sur mobile reste acquise : invitations à zéro, puis
compteurs ; heure et état à droite. Cette précision ajoute la redondance voulue
dans le menu, elle ne supprime pas le pied compact.

## Recette complémentaire

Vérifier message personnel, message d’autrui, réponse dans le fil et réponse
dans la discussion liée. Les trois interactions doivent viser le même objet
depuis le pied et depuis « … ». Après mise à jour, tester également les
opérations de gestion et le retour de focus, sans réintroduire de faux succès.

Le constat de recette du jour montre encore des menus personnels limités à
Modifier/Supprimer dans le canal du Monde 1. C’est l’état observé, qui reste à
aligner sur cette précision ; ce n’est pas une validation de menus sans les
trois interactions.
