## Convention

Chaque script précise :

- fonction pédagogique et place exacte dans le parcours ;
- durée et rythme visés ;
- voix off intégrale ;
- intentions visuelles, sonores et textes à l'écran ;
- transition vers l'action suivante ;
- garde-fous éditoriaux et points restant à arbitrer.

La voix suit la [charte Point Zéro](../../vision/voix-point-zero.md) : adulte, lucide,
légèrement provocatrice, poétique mais concrète, avec un humour discret dirigé vers les systèmes,
le dispositif et nos contradictions partagées.
