# Monde 0 — gravures des trois chapitres

du parcours. Direction retenue : **conte de fées néoarchaïque adulte**, traité comme une gravure
ancienne recomposée en collage contemporain.

## Série monochrome retenue

Après arbitrage, les chapitres restent dans un registre de **gravure monochrome** : encre noire,
papier ivoire et sépia provenant uniquement du vieillissement du support. Les variantes colorées
V1 des chapitres 2 et 3 sont conservées comme essais, mais remplacées pour la suite par :

- `02-je-relie-la-constellation-v2-monochrome.png` ;
- `03-je-prends-place-la-chaise-vide-v2-monochrome.png`.

## Invariants graphiques

- format carré, composition centrée pour le recadrage circulaire de l'application ;
- lisibilité visée à 170 px sur mobile ;
- un symbole dominant par chapitre : fissure, constellation ouverte, chaise vide ;
- figures oniriques composées de fragments gravés et de papiers collés ;
- progression lumineuse : graphite et ivoire au chapitre 1, cuivre et turquoise au chapitre 2,
  ivoire et ambre au chapitre 3 ;
- symétrie entre Point Zéro individuel et collectif matérialisée par une même ligne intérieure et
  extérieure ;
- aucun texte, numéro, logo ni élément d'interface incrusté.

## Usage

Ces fichiers sont des sources versionnées. Ils peuvent être chargés dans l'image de la `Page`
correspondante sans écraser les anciens pilotes 16:9. L'interface les affiche en médaillon de
210 px sur ordinateur et 170 px sur mobile, ainsi qu'en vignette de 54 px dans le sommaire.
