## Direction artistique retenue

Scènes narratives d'« Une drôle d'époque » et d'« Avant le Zéro » : personnages
expressifs, décors contemporains, tessellation en mosaïque, matières minérales,
lignes dorées. Les symboles inspirés du Point Zéro font partie du décor.
Les figures en masques de papier de la V2 ne sont pas la version retenue.

## Reprise par le portable

1. Utiliser ces quatre fichiers selon le format réel de l'événement, en distinguant
   l'atelier en ligne de l'atelier présentiel. Aucune nouvelle catégorie ou route
   n'est définie par cette livraison d'images.
2. Les rattacher aux cartes et fiches d'événement concernées de l'agenda. Garder
   les titres et informations comme texte HTML, les images n'en contiennent pas.
3. Préserver les sources PNG. Les éventuels dérivés WebP doivent conserver le
   rapport 3:4 et les motifs ; vérifier le cadrage des visages et symboles dans
   les emplacements qui recadrent les images, notamment sur mobile.
4. Vérifier les quatre affectations en préprod. La transmission des sources ne
   constitue pas une publication effectuée par Codex.

Le visuel du Festival ne fait pas partie de ce lot. Aucun code applicatif, tarif,
contenu d'inscription ou donnée de compte n'a été modifié.

visuelles utilisées, les dimensions et les empreintes SHA-256. Les copies ont été
comparées aux sources ; les quatre PNG sont valides et de ratio 3:4 exact.
